# 粤讲粤掂 · 从零开始学粤语（普通话母语者专属）

> 网站名「粤讲粤掂」谐音"越讲越掂"——掂（dim6）= 搞定、妥当。越讲，越掂！

## 怎么部署

**方式一（自由试听，零安装）**：双击 `index.html`（推荐 **Microsoft Edge** 或 **Chrome**）。计划学习和进度保存需要服务器模式登录。

**方式二（多用户服务器部署）**：服务器安装 Node.js 18+，上传整个文件夹后：

```bash
node server.js                 # 默认 3000 端口
PORT=80 node server.js         # 指定端口（Windows: set PORT=80）
```

- 访问 `http://服务器IP:端口`；顶栏出现「👤 登录」：注册后打卡与成绩自动同步云端（账号数据在 `server-data/users.json`，备份=拷贝该目录）。
- 局域网使用：防火墙放行端口即可，家人手机/电脑都能访问，各自注册互不干扰。
- 生产建议：`npm i -g pm2 && pm2 start server.js --name ygt && pm2 save`（开机自启、崩溃重启）；再配 Nginx 反向代理 + HTTPS 证书更稳妥。
- 零 npm 依赖、无数据库要求；公网部署前请移除 `media/songs/` 里的版权音频（网站功能不依赖它们）。

## 进度存在哪里

90 天计划必须登录后使用。打卡和测验最佳成绩按账号保存到服务器 `server-data/users.json`；不同账号互相隔离。退出后清空页面上的当前进度，登录时只读取该账号的服务器记录，不合并历史匿名缓存。浏览器缓存也使用账号前缀。登录凭据使用每个标签页独立的 sessionStorage，支持不同标签页登录不同账号。

歌曲时间标记、已学会句子和注音修正按账号保存在本机，不跨设备同步；未登录可试听但不能保存学习记录。历史匿名记录不会自动归属到任何账号。服务器禁止访问用户数据库和服务端源码。

## 粤语发音教学音源

声母保留原来的完整音节呼读方式（如 b → baa1）。韵母主按钮固定播放「粤拼方案」的完整示范字录音（如 飞 fei1、剑 gim3），标明字、粤拼、声母、韵母和声调。55 项均对应页面已有的明确例字；a、eo 是韵腹，分别在 心 sam1、出 ceot1 中体会，不把整个 am/eot 当作 a/eo。播放映射见 `js/phonetic-lessons.js`。`media/phonemes/` 中的试验素材保留，但教学按钮不再播放它们。

声母呼读和普通例字由顶部音色选择控制：默认香港中文大学字库（392 个 WAV，原网页致谢陈京英老师），也可选原录音（多位）。韵母主按钮与拼读中的韵母示范固定使用 `media/pronunciation/` 的「粤拼方案」完整 MP3，保留原声，不截取或拼接；不承诺这套录音均为同一说话者。来源缺少 ge3、hai2、nam2 等整字音节时会提示。

参考 [粤语通](https://neihou.cn/jyutping) 的“发音方法 + 例字练习”组织方式。检查该站当前脚本发现它用浏览器 TTS 朗读例字，并非独立韵母真人录音库；未复制其教材或采用其普通话 TTS 兜底。试验用截音构建工具只作历史保留，不属于当前教学音源维护流程。

原录音保存在 `media/pronunciation/`，索引为 `js/pronunciation-map.js`，来源、校验值和仓库许可见同目录的 `CREDITS.json` 与 `LICENSE.txt`。补下载：

```bash
node tools/fetch-pronunciation.js
```

补下载支持环境变量及 Windows 手动系统代理，也可明确指定代理或直连：

```bash
node tools/fetch-pronunciation.js --direct
node tools/fetch-pronunciation.js --proxy http://127.0.0.1:实际端口
```

脚本使用系统 curl，检查 MP3 文件头及已缓存文件的 SHA-256，支持断点续跑。不要用浏览器是否能打开网页推断命令行代理状态。

拼读“你”分步播放 naa4（声母呼读）→ fei1（韵母示范）→ nei5（目标字）；这些是示范步骤，不是把三个音直接连成一个字。一次点击只播一个完整录音，停止、切页或点击其他内容会取消旧播放。运行 `node tools/check-lesson-audio.js --direct` 可逐项与在线源校验音频字节；这不代替教师听审。

`media/ipa/` 中部分辅音录音用作截取来源，完整 IPA 文件不直接连播给学习者；通用 IPA 参考音不等于粤语口音的全部细节。`js/synth.js` 仍不参与基础教学。没有粤语 TTS 时不会默默回落到普通话。

## 发音准确性

粤拼注音可用 **Unicode Unihan 粤音数据库** 复核，运行 `node tools/audit.js`。这只检查汉字读音字符串，不检查录音内容、音源与按钮的对应关系、例字是否属于当前声韵母，也不能代替听审。基础发音的自动检查另见 `node --test tests/pronunciation.test.js`；音色、细微音值与口形仍建议配合粤语教师示范核对。

## 放自己的歌曲音频（可选）

把有权使用的音频和歌词放在 `media/songs/`，启动 `node server.js`。页面自动加载该目录，优先恢复上次选择的歌曲，否则加载第一首；同名歌词自动解析：

- 歌曲：`media/songs/歌名.mp3`；歌词：同目录 `歌名.lrc` 或 `歌名.txt`，LRC 优先。支持任意歌名，不限预设曲目。
- 也可选择多个音频和歌词，或选择整个文件夹；相同目录和名称自动配对。直接双击 HTML 时使用 `js/local-songs.js` 的本地索引，当前三首歌曲及歌词已收录。新增文件后运行 `node tools/index-songs.js` 更新索引，或使用文件夹加载。浏览器无法在 file 模式中任意扫描磁盘目录。
- LRC 保留时间戳、offset、重复段落；每句可播放原唱或循环。TXT 无时间信息，播放到句首、句尾分别点击「设起点」「设终点」，再点「原唱单句」。时间及已学会状态保存在本机浏览器，不同步到账号。
- 点字查看声母、韵母、声调并试听；多音字默认注音仅供参考，可修改本句粤拼并保存。整句「朗读」使用系统粤语 TTS，与「原唱单句」分开。
- 优先加载同名歌词，再尝试 ID3v2.3/2.4 USLT/SYLT 内嵌歌词；不支持的压缩标签或帧计数时间戳需另配 TXT/LRC。支持 UTF-8、UTF-16、GB18030 文本。
- 支持 mp3/m4a/ogg/wav，0.6–1.0 变速、单句循环、停止及切页自动停音。歌曲页已移除外链入口。

> 音频请自行合法获取并仅用于个人学习；公开部署前请移除受版权保护的音频。

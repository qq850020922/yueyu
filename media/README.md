# media/ · 本地资源目录（可选）

把你找到的音频放进对应子目录，网站**自动识别并出现播放器**，无需改代码：

| 用途 | 放哪里 | 文件名 |
|---|---|---|
| 歌曲 | `media/songs/` | 与网站歌名一致，如 `上海滩.mp3`、`海阔天空.mp3` |
| 诗歌朗读 | `media/poems/` | 与诗名一致，如 `静夜思.mp3` |

- 支持格式：mp3 / m4a / ogg / wav（优先尝试 mp3）。
- 文件名即配置：`歌名.mp3` 对应歌曲页《歌名》；`诗名.mp3` 对应诗歌页《诗名》。
- **指定教学段落**（比如只练副歌 30 秒）：编辑 `media/manifest.json`，填 start/end 秒数（仅服务器模式需要；双击 index.html 的本地模式直接按文件名识别，用播放器的 A/B 按钮手动选段即可）。
- 播放器自带 0.5–1.0 变速与 A-B 段循环——跟唱时把速度调到 0.75、循环副歌段最佳。

> 提示：音频请自行从合法渠道获取并仅用于个人学习；部署到公网分享前请移除受版权保护的音频文件。
